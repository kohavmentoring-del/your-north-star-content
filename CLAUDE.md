# Your North Star - content repo

Kohav's English Instagram/TikTok brand. Read `brand/voice.md` first, always.

- New reel: use the `reel-kit` skill. One folder per reel in `reels/NNN-slug/`.
- `schedule.md` is the posting calendar. Keep it current when a kit changes status.
- `scripts/setup.sh` runs at session start and installs the ig-* skills plus the voice profile.
- No selling or paid promotion until May 2027. This account only builds community.
- Connectors used: HyperFrames (motion graphics), Canva (covers), PostZen (scheduling, optional).
